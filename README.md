# 清一新教育 · 知乎文章修改本地执行器

给知乎文章批量加品牌署名的**本地工具**：每篇文章固定改动 2 处 ——
标题最前面加 `【清一新教育】`（1 处）+ 正文句末加 `（清一新教育）`（1 处）。
其余内容一个字都不动，且每篇改动前自动备份、可一键还原。

> **为什么必须在本地跑？** 知乎写入必须来自**你自己的电脑和你的网络身份**，
> 服务器机房 IP 批量写入会触发风控。

## 这一版的分工（v5）

```
    网页端（控制面）                你的电脑（数据面）            知乎
  ┌──────────────────┐          ┌────────────────────┐        ┌──────┐
  │ 1. 勾选文章、建任务 │          │                    │        │      │
  │ 2. 云端算好每篇的  │  缓存 →   │ 3. 取回云端算好的  │  写入  │ 文章 │
  │    「最终标题+正文」│          │    那一份，原样上传 │ ────→  │      │
  │ 4. 云端重新回读线上│  ←回读─  │                    │        │      │
  │    逐篇比对 → ✓/✗ │          │                    │        │      │
  └──────────────────┘          └────────────────────┘        └──────┘
```

- **内容由云端算好**：云端用统一的规则算出每篇文章的最终稿并缓存，
  本地执行器**原样提交**，不自己改写、不自己决定加在哪里。
- **结果由云端复核**：写完以后云端会**重新回读线上文章**，逐篇校验
  —— 标题是否只多了前缀、正文是否只多了一处括注、品牌词是否恰好 +1、
  其余文字是否逐字未变 —— 然后给出 `pass` / `fail`。
  云端**不采信**「本地说做完了」。

## 傻瓜三步（不需要粘贴任何东西）

**前提**：你的浏览器（Edge 或 Chrome）已登录 [zhihu.com](https://www.zhihu.com)。

1. 点本页绿色 **Code** 按钮 → `Download ZIP` → 解压到桌面或任意文件夹。
2. 双击：
   - Windows：`一键部署-Windows.bat`
   - macOS：`一键部署-Mac.command`（首次可能弹钥匙串授权，点「始终允许」）

   它会自动：装依赖 → **从你的浏览器读取知乎登录**（零粘贴、零 F12）→
   把凭证暂存到云端 → **请云端把该任务每篇的最终稿算好** → 启动执行器。
3. 打开 [文章修改工作台](https://zh.samuraiguan.cloud/api/qy/console) →
   点 **📥 载入凭证** → 勾选文章 → 创建修改任务 → 点 **📋 复制给助手的指令**，
   把那段话发给你的 AI 助手。

执行器会自动领取任务并逐篇上传；全部做完后会在窗口里直接打印**云端复核结果**：

```
[云端复核] 校验 12 篇 | 通过 11 | 不通过 1 | 未校验 0
   ✗ 2012970947553014369：正文未按云端方案植入品牌词（线上找不到品牌括注）
```

内置安全机制（自动生效）：每天最多 120 篇、每小时 12 篇、篇间随机间隔、
连续失败自动中止、每篇改动前本机备份。

## 常见问题

- **提示浏览器正在运行并锁定了数据文件？**
  完全退出 Edge / Chrome（关闭所有窗口，包括任务栏托盘图标），再运行一次部署器。
  部署器会自动给出 3 次重试机会。
- **想手动粘贴凭证？** 一般不需要。把从知乎复制的 Cookie 保存为 `cookie.txt`
  放进本目录，部署器会自动改用它。
- **云端复核说某一篇 fail 怎么办？** 按它给出的原因处理（例如「正文未植入」），
  然后重新跑一次执行器即可 —— 预修改是幂等的，不会重复加第二处。
- **如何停止？** 执行器窗口按 `Ctrl+C` 或直接关窗口，随时安全停止，次日继续。

## 隐私与安全

- `cookie.txt` 已在 [.gitignore](.gitignore) 中排除，**永远不会**被提交到本仓库。
- 凭证只保存在你自己的电脑；云端暂存副本 6 小时后自动消失（仅内存，不落盘），
  用于网页端「载入凭证」与云端复核。
- 执行器只调用知乎的草稿/发布接口完成上述 2 处署名修改，不做任何其他写入。
