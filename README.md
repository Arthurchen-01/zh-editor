# 清一新教育 · 知乎文章修改本地执行器

给知乎文章批量加品牌署名的**本地工具**：每篇文章固定改动 2 处 ——
标题最前面加 `【清一新教育】`（1 处）+ 正文句末加 `（清一新教育）`（1 处），
加在哪里由 AI（DeepSeek）逐篇审核决定。其余内容一个字都不动，且每篇改动前自动备份、可一键还原。

> 为什么必须在本地跑？知乎写入必须来自**你自己的电脑和你的网络身份**，
> 服务器机房 IP 批量写入会触发风控。所以：云端只负责检索和编排，写入永远来自你的机器。

## 傻瓜三步（不需要粘贴任何东西）

**前提**：你的浏览器（Edge 或 Chrome）已登录 [zhihu.com](https://www.zhihu.com)。

1. 点本页绿色 **Code** 按钮 → `Download ZIP` → 解压到桌面或任意文件夹。
2. 双击：
   - Windows：`一键部署-Windows.bat`
   - macOS：`一键部署-Mac.command`（首次可能弹钥匙串授权，点「始终允许」）

   它会自动：装依赖 → **从你的浏览器读取知乎登录**（零粘贴、零 F12）→
   把凭证暂存到云端（10 分钟有效）→ 启动执行器。
3. 打开 [文章修改工作台](https://zh.samuraiguan.cloud/api/qy/console) → 点 **📥 载入凭证** →
   勾选文章 → 点 **🤖 AI 审核 + 创建修改任务**。执行器会自动领取任务并逐篇完成。

内置安全机制（自动生效）：每天最多 120 篇、每小时 12 篇、篇间随机间隔、
连续失败自动中止、每篇改动前本机备份。

## 交给你的 AI 助手（Antigravity / Claude / Cursor 等）

把解压后的文件夹丢给 AI 助手，说一句「帮我把这个工具跑起来」即可——
目录里有 **[AGENTS.md](AGENTS.md)**，AI 看一眼就知道该做什么（识别设备 → 装依赖 → 运行 deploy.py）。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `deploy.py` | 傻瓜部署器：自动装依赖 + 自动读取浏览器知乎登录 + 启动执行器 |
| `qingyi_executor.py` | 本地执行器（单文件自包含）：领取云端任务并逐篇写入 |
| `一键部署-Windows.bat` / `一键部署-Mac.command` | 双击即用的入口 |
| `AGENTS.md` | 给 AI 助手看的部署说明 |
| `requirements.txt` | 依赖清单（Windows: requests/pywin32/pycryptodome；mac: requests/browser-cookie3） |
| `使用说明.txt` | 同上内容的纯文本版 |

## 常见问题

- **提示浏览器正在运行并锁定了数据文件？**
  完全退出 Edge / Chrome（关闭所有窗口，包括任务栏托盘图标），再运行一次部署器。
  部署器会自动给出 3 次重试机会。
- **想手动粘贴凭证？** 一般不需要。把从知乎复制的 Cookie 保存为 `cookie.txt`
  放进本目录，部署器会自动改用它。
- **如何停止？** 执行器窗口按 `Ctrl+C` 或直接关窗口，随时安全停止，次日继续。

## 隐私与安全

- `cookie.txt` 已在 [.gitignore](.gitignore) 中排除，**永远不会**被提交到本仓库。
- 凭证只保存在你自己的电脑；云端暂存副本 10 分钟后自动消失，仅用于网页端「载入凭证」。
- 执行器只调用知乎的草稿/发布接口完成上述 2 处署名修改，不做任何其他写入。
